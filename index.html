Effects Engine

🌌

Mesh Particles

Cyan + purple particles with connection lines and lightning bolts between distant nodes.

⚡

Lightning Bolts

Zigzag lightning effect between far particles (>60px). Close particles get straight connection lines.

💥

Hacker Glitch

Full-screen scanlines, random characters, RGB channel split. Fires on word match. Duration ~750ms.

💨

Smoke Effect

New words rise upward like smoke and fade out. Word dissipation animation on first-time typed words.

💣

Flash Overlay

Full-screen color flash on word match. Red for special words, green for repeated words.

💢

Screen Shake

Window shakes on word match. 8 random offset points with 30ms intervals. Skipped in minimized mode.

✨

Particle Explosion

Burst of particles from center on word match. Color matches the trigger type.

🎵

Sound Effects

Digital chime sounds on word match. Separate sounds for special vs normal word matches.

👁

Ghost Typing

Shows your current keystrokes in real-time on the overlay panel as you type.

🚀

Mesh Overlay

Full-screen particle mesh animation on word match. Auto-fades after 600ms with opacity decay.

🔥

Welcome Splash

Matrix rain + glitch text animation on startup. Click/Space/Esc to skip. Auto-fades to main UI.

📷

Window Slide-in

Smooth OutCubic animation when restoring from minimized. Slides in from right edge (350ms).

// CORE FEATURES

What It Does

01

Real-Time WPM Tracking

Calculates words per minute using a 12-second sliding window. Updates live on the overlay panel.

02

Word Match Detection

Compares every typed word against SQLite database. Repeated words trigger green effects, special words trigger red.

03

Special Word Triggers

Custom words stored in database. Typing them triggers enhanced effects — red flash + glitch + mesh + explosion.

04

Click-Through Mode

Minimized mode uses WindowTransparentForInput flag. Overlay is visible but doesn't block mouse/keyboard input.

05

App Usage Monitoring

Tracks which applications you use and for how long. Alerts you when usage exceeds threshold.

06

Minimized Overlay Mode

Compact 250x110px panel. Mesh particles still run. Word match effects are skipped to prevent visual clutter.

07

Crash Logger

sys.excepthook writes all errors to crash.log with timestamp, line number, and full traceback.

08

Tray Menu Control

System tray icon with context menu. Toggle effects, minimize/restore, access settings, and quit app.
